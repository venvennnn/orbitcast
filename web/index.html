OrbitCast

Podcasts that don't go stale. Type a topic once — get a real RSS series that keeps publishing.

Not another NotebookLM dump

  • Living series, not a file. NotebookLM gives you one audio export. OrbitCast gives you a subscribe-able RSS feed in a normal podcast app.
  • Change-aware episodes. Each run sees the last scripts and reports only what’s new — or skips when nothing episode-worthy happened.
  • Keeps going by itself. Cron re-enqueues active feeds on a schedule; hit Refresh live for episode #2 on camera.

Built on Zerops

  • web · nginx dashboard
  • api · FastAPI CRUD + RSS
  • worker · research → TTS → upload
  • cron · scheduled enqueue
  • db · managed PostgreSQL
  • queue · managed Valkey (BRPOP)
  • objectstorage · public MP3s (S3/MinIO)

Private networking between services; only web + api are public.
